# Contenido público VNAMJ

Este repositorio es INDEPENDIENTE de `project.vnamjconfecciones`.

- `trabajos.json`: publicaciones del taller.
- `imagenes/trabajos/`: fotografías autorizadas.
- `.pages.yml`: campos del editor Pages CMS.

**Aviso de privacidad:** todo lo que se suba a este repositorio público puede ser visto, incluso si `publicado` es `false`. No cargar datos privados, fotografías no autorizadas, contraseñas ni información de clientes.

La cuenta de la community manager se configura en GitHub + Pages CMS, con 2FA.
Para que la web lea este repositorio, configura `src/config/contenido.ts` en el sitio.
